# گزارش کارتابل تسک‌ها (کاملا مجزا)

این بخش به صورت **کاملا مستقل** از سایر فایل‌های پکیج `behin-simple-workflow` ساخته شده است.

## ساختار فایل‌ها

```
src/Report/
├── Routes/report.php                  ← فقط روت‌های این گزارش
├── Controllers/ReportController.php    ← فقط کنترلر این گزارش
└── Views/index.blade.php               ← فقط ویوی این گزارش (تم ارغوانی)
```

## نحوه ثبت (تنها تغییر بیرون از این پوشه)

در `src/SimpleWorkflowProvider.php` فقط دو خط زیر اضافه شده است:

```php
$this->loadRoutesFrom(__DIR__ . '/Report/Routes/report.php');
$this->loadViewsFrom(__DIR__ . '/Report/Views', 'SimpleWorkflowReportView');
```

## آدرس‌ها

| روش | آدرس | نام روت | توضیح |
| --- | --- | --- | --- |
| GET | `workflow/report` | `simpleWorkflow.report.index` | صفحه گزارش (انتخاب فرایند و تسک) |
| GET | `workflow/report/tasks` | `simpleWorkflow.report.tasks` | لیست تسک‌های **فرم** یک فرایند به صورت JSON (برای انتخاب‌گر وابسته) |

> کارهای کارتابل فقط از جنس «فرم» هستند؛ بنابراین تسک‌های اسکریپت، شرط و سایر انواع
> نه در لیست انتخاب تسک می‌آیند و نه اگر آیدی آن‌ها دستی داده شود گزارشی ساخته می‌شود.
> آیکون‌ها از Font Awesome (`fa fa-*`) هستند که در لایه اصلی اپ لود می‌شود.

مثال: `http://localhost/optic/workflow/report`

> برای افزودن به منوی کنار (اختیاری) فقط این سطر را به `config/sidebar.php` اضافه کنید:
>
> ```php
> 'report-inbox' => [ 'fa_name' => 'گزارش کارتابل تسک', 'route-name' => 'simpleWorkflow.report.index' ],
> ```

## خروجی گزارش برای یک تسک

- تعداد کارهای باز در کارتابل کاربران + تعداد کاربران دارای کار
- قدیمی‌ترین کار در انتظار + کل کارهای ثبت‌شده در تسک (باز و بسته)
- چیپ تعداد کارها به تفکیک وضعیت (`new`, `opened`, `inProgress`, `draft`, `done`, `canceled`, ...)
- لیست کاربران: تعداد کار در کارتابل هر کاربر، سهم درصدی، تاریخ قدیمی‌ترین و آخرین کار،
  و با باز کردن هر کاربر، لیست پرونده‌های داخل کارتابل او (با لینک به صفحه کارتابل)
- کارهای باز «بدون کاربر» (کارتابل سیستمی) به صورت جداگانه نمایش داده می‌شوند

## نکات فنی

- وضعیت‌های باز از `config('workflow.inboxStatus')` خوانده می‌شوند (همان منبع سایر بخش‌های پکیج).
- تاریخ‌ها با `Morilog\Jalali` (وابستگی خود پکیج) شمسی می‌شوند؛ نیازی به هلپرهای اپلیکیشن نیست.
- حداکثر پرونده نمایش داده شده برای هر کاربر: `ReportController::CASES_PER_USER` (پیش‌فرض ۱۰)
- حداکثر رکورد خوانده شده برای جزییات: `ReportController::DETAIL_ROW_LIMIT` (پیش‌فرض ۵۰۰۰)
